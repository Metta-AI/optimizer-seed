# CTF lab documentation

Authoritative game rules and source remain in
`https://github.com/Metta-AI/coworld-ctf`. This directory contains lab-local
records only; it intentionally does not duplicate the upstream source.

Key mechanics recorded during orientation:

- 8v8 / 16 seats with `team_pair` seating.
- Decisive score `+1/-1`; timeout draw `-1/-1`; mutual wipe `0/0`.
- Plasma arc, shield, med-kit, grenade, and shout mechanics.
- Ten-character shouts, friendly fire, and five-tick hitscan windup.
- Vision documentation has a 45-degree manifest value and approximately
  ±60-degree prose value; retain the discrepancy.
