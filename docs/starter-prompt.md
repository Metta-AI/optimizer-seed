# Starter prompt

A copy-paste prompt for a brand-new user to hand their coding agent as their
first message. They don't need this repo yet — the agent clones it and runs
the guided onboarding.

---

I want to compete in Softmax Coworld leagues — games where player programs
("policies") compete on public leaderboards — and I want my own optimizer:
a workspace that helps me understand a game, improve a policy with my own
strategy, and get better over time.

Please:

1. Clone the optimizer seed: `git clone <SEED_REPO_URL> my-optimizer`
   (pick a directory name I'll keep — this becomes *my* optimizer).
2. `cd my-optimizer` and read `AGENTS.md` — it's your operating doctrine in
   this repo, including how we work together.
3. Wire up your runtime per `harness/README.md` (there are ready-made
   configs for common agent harnesses; install the one that matches you, or
   self-wire and record what you did).
4. Then start `docs/getting-started.md` and guide me through it. I may be
   completely new to Softmax and to these games — act as my guide, not just
   a coding agent.

---

*(Maintainers: replace `<SEED_REPO_URL>` with the published seed repository
URL when releasing.)*
