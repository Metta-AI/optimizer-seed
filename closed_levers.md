# Closed levers — do not re-chase

A short risk register of refuted levers: improvement ideas that were tested and
killed, with the numbers that killed them. `diagnose` consults this before
proposing; re-opening an entry requires *new evidence*, not a new label on the
same mechanism.

This is a register, not an archive — keep entries to a few lines and point at
the experiment record that holds the details. Game-specific levers belong in
the lab's own `closed_levers.md`; only optimizer-wide (process/meta) levers
live here.

Format:

```
## <lever name>                                    closed YYYY-MM-DD
**Mechanism:** what the idea was, in one sentence.
**Killed by:** the measured result (numbers), with a link to experiments/<id>.md.
**Would reopen if:** the specific new evidence that would justify another look.
```
